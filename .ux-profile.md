# UX profile

## Notes

- **Motion exception, marketing page only** (`site/index.html`, outside the app shell). Three brand animations run off the 100–300ms token scale on purpose: the hero's glitch load-in (900ms), Clawde's breathing bob (3.2s loop, the same as the app's `clawde-bob`) and the sweat drip (4s loop). All three stop under `prefers-reduced-motion`. Everything else on the page uses the motion tokens.
